# grocTrac

A crowdsourced grocery price tracking platform that helps users find the cheapest items and compare prices across nearby stores.

## Project Overview

grocTrac is a mobile and web application that leverages community participation to build real-time grocery pricing data. Users contribute by uploading photos of their grocery receipts, which are then used to create a comprehensive, up-to-date database of product prices across different stores in their area.

## Key Features

### 📱 Receipt Upload & Scanning
- Users can capture and upload photos of grocery store receipts
- Automated or manual entry of scanned receipt data
- Contributors are rewarded for verified data submissions

### 💰 Price Comparison
- View the cheapest prices for specific grocery items across nearby stores
- Compare identical products across multiple retailers
- Track price trends over time

### 🗺️ Store Locator & Mapping
- Interactive map view of nearby grocery stores
- Distance calculations and store ratings based on price competitiveness
- Store-specific pricing information and inventory availability

### 🌐 Online Price Integration
- Web scraping of online grocery store prices
- Integration with major retailers' APIs
- Real-time price data from e-commerce platforms
- Compare online vs. in-store prices

### 🎯 Smart Recommendations
- Get notifications when favorite items go on sale
- Personalized shopping recommendations based on store locations
- Budget tracking and savings optimization

## How It Works

1. **Users contribute** by uploading receipt scans or manually entering grocery prices
2. **Data is aggregated** into a crowdsourced database organized by location and store
3. **Platform analyzes** the data to identify pricing patterns and best deals
4. **Community benefits** from real-time price comparisons and store recommendations
5. **Online integration** supplements crowdsourced data with official pricing from retailers

## Tech Stack

- **Backend**: Python (FastAPI)
- **Frontend**: Next.js / React
- **Database**: PostgreSQL with PostGIS for location-based queries
- **Scraping**: Web scraping tools for online retailers
- **Maps**: Leaflet or Google Maps API for location visualization
